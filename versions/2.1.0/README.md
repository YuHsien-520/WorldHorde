# WorldHorde 2.1.0 — 尸群智能更新

Minecraft Java Edition 1.12.2 / Java 8。

## 本版重点

- 智能多人仇恨导演：权重概率索敌、软集火限制、目标粘性、追击失败换目标。
- 尸潮余孽 / 威胁债务：上一场未完全清剿会强化下一场，完整清剿可削减债务。
- 协同攻城：同一突破口 2 / 3 / 4 / 5+ 名攻击者总效率约 1.8x / 2.5x / 3.1x / 3.5x。
- 延续 A/B/C 世界攻城、自动修复、远距离追猎、末尾猎杀与 TPS 自适应限流。
- 延续 YXClientEngine GUI / HUD / BGM / 粒子 / World Marker 沉浸表现。
